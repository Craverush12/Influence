## 💡 Key Principles (Memorize These!)

### ✨ When Building Components:
- Use **Playfair Display** for headings (serif = premium)
- Use **Inter** for body text (clean, modern)
- Use **Terracotta** (#CC6644) for accent highlights
- Use **warm gradients** (Plum → Terracotta) for CTAs
- Apply **accent bar** (left 4px border) for emphasis
- Use **12-16px border radius** (softer, not sharp)
- Use **matte surfaces** (not glossy glass)
- Create **warm shadows** (not black shadows)

### ❌ What NOT to Do:
- Don't use blue/cyan colors (old aesthetic)
- Don't use glossy glass effects (use matte)
- Don't use sharp 8px corners (use 12-16px)
- Don't use flat designs with no depth
- Don't use sans-serif for headings (use serif)
- Don't use harsh white text (use cream)
